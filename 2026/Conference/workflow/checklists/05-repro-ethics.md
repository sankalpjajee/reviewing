# Stage 5 — Reproducibility, ethics, licensing, checklist audit

## Artifact availability

- [ ] Artifact URL present in the paper — record verbatim, or record "none found"
- [ ] Anonymised for review, permanent for camera-ready
- [ ] Licence of the new artifact stated
- [ ] Licences of **all** source assets named, not gestured at
- [ ] Source licences actually permit redistribution of the derived form
- [ ] Datasheet / dataset card, hosting, maintenance plan

## Reproducibility

- [ ] Learning rate, batch size, optimiser, steps/epochs
- [ ] Seeds and number of runs
- [ ] Hardware and wall-clock/GPU hours
- [ ] Model versions and checkpoints
- [ ] Preprocessing and evaluation code paths described or released

## Ethics

- [ ] Dual-use discussed concretely
- [ ] Safeguards proportionate to the risk, and actually about safeguards
- [ ] PII and consent in source imagery, especially person-centric categories
- [ ] Human-subjects/IRB status consistent with what was actually done
